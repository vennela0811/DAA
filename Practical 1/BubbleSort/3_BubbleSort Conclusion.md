Bubble Sort is primarily an educational tool used to introduce basic algorithmic concepts and element comparisons.
It suffers from a poor average and worst-case time complexity of $O(n^2)$, making it inefficient for large datasets.
Despite this limitation, it requires zero auxiliary memory with an in-place space complexity of $O(1)$ and remains stable.
An optimized implementation can achieve an $O(n)$ best-case time complexity when processing already sorted arrays.
Ultimately, it serves in DAA as a baseline brute-force approach to contrast with advanced divide-and-conquer algorithms.
