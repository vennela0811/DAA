Heap Sort constructs a binary heap data structure to repeatedly extract the extreme element and place it in sorted order.
It guarantees a reliable time complexity of $O(n \log n)$ across best, average, and worst-case scenarios.
It operates entirely in-place requiring an optimal auxiliary space complexity of $O(1)$.
However, it remains an unstable sorting algorithm with higher constant overhead factors compared to quick sort.
In DAA, it serves as a core example of transform-and-conquer techniques leveraging tree structures for efficient sorting.
